# CI tooling branch — do not use for radio testing

This branch exists only to build and publish the frozen Hybrid SDR A/B/C/D test set.

Use the compiled packages on the release page or the corresponding product branch. Branch D is the hardware-validated final design: configure its independent processed-TX route under Setup -> Audio -> TX Output, while VAC2 remains available for its normal RX2 role.
